User Manual

Guide to authenticate, permissions, and every Admin / Dashboard API endpoint in the current codebase.

Admin API

JWT-protected. Manage users, roles, projects, tasks, profile, and overview stats.

Dashboard API

Public read-only projects. Closed projects (CLOSE) are hidden.

Realtime

Socket.IO events for project and task create / update / delete.

1. Introduction

JSON over HTTP. Admin endpoints require a Bearer token from sign-in. Updates use POST on resource paths (not PUT/PATCH).

2. Base URL

http://<host>:<port>/api

Example: http://localhost:3030/api

3. Authentication

  1. Call POST /admin/v1/auth/sign-in with email and password.
  2. Receive JWT token (valid 30 days).
  3. Send on protected requests:
Authorization: Bearer <token>
Content-Type: application/json

4. Permissions

Based on the signed-in user’s role permission.

Action FULL_CONTROL PROJECT_MANAGEMENT
Sign in / profile (/me) / overview / list & detail Yes Yes
Create / update / delete users Yes No (403)
Create / update / delete roles Yes No (403)
Create projects Yes No (403)
Update projects & tasks Any project Only owned projects
Project owners must be ACTIVE users with role permission PROJECT_MANAGEMENT.

5.3 Task → project sync

On task create / update / delete:

  1. project.totalPercentage = average of all task completedPercentage values.
  2. Tasks are grouped by status; each group sums completedPercentage.
  3. The group with the highest sum wins (tie-break: higher count).
  4. That status is written to project.status.
  5. If the project is already CLOSE, status is not changed.
  6. If there are no tasks left, project status becomes OPEN.

6. Conventions

  • Pagination: page + perPage
  • Filters: query params matching field names
  • Project codes: auto PMO0001, PMO0002, …
  • TAC: DD-MM-YYYY (e.g. 15-08-2026)
  • Password: min 8 chars with upper, lower, number, special
  • Hidden role: Developer is never returned in role list/detail

12. Projects

JWT

GET/admin/v1/projects

Filters: code, name, department, status, stage, ownerId, and other project text fields.

GET/admin/v1/projects/:id

Includes projectOwners and tasks. Task TAC is DD-MM-YYYY.

POST/admin/v1/projects

Requires FULL_CONTROL. ownerIds required (1+). code auto-generated.

{
  "name": "Core Banking Upgrade",
  "department": "IT",
  "status": "OPEN",
  "stage": "INITIATION",
  "ownerIds": [3, 5]
}
POST/admin/v1/projects/:id
  • FULL_CONTROL: any project
  • PROJECT_MANAGEMENT: only if owner
  • Manual COMPLETED requires all tasks COMPLETED and total 100%

13. Tasks

JWT · Create/update/delete allowed for full-control users, or owners of the related project.

MethodPath
GET/admin/v1/tasks
GET/admin/v1/tasks/:id
POST/admin/v1/tasks
POST/admin/v1/tasks/:id
DELETE/admin/v1/tasks/:id

List filters: name, tac (DD-MM-YYYY), projectId, projectCode, status.

{
  "name": "UAT sign-off",
  "tac": "15-08-2026",
  "completedPercentage": 50,
  "projectId": 1,
  "status": "ON_TRACK"
}
After create/update/delete, the API recalculates project totalPercentage and sets project status to the task-status group with the highest summed completedPercentage.

14. Dashboard Projects (Public)

No auth. Read-only. Projects with status CLOSE are excluded from list and detail (detail returns 404).

MethodPathDescription
GET /dashboard/v1/projects List (filters include code, status, ownerId, …)
GET /dashboard/v1/projects/:id Detail with owners and tasks

15. Realtime (Socket.IO)

Live updates when projects or tasks change. Path: /socket.io (same host/port as the API, without the /api prefix).

http://<host>:<port>

Example: http://localhost:3030 · path /socket.io

Connection

  • Anonymous — allowed (public dashboard).
  • Admin JWT — optional via auth.token or Authorization: Bearer <token>. Must be loginType: "admin".
import { io } from "socket.io-client";

const socket = io("http://localhost:3030", {
  path: "/socket.io",
  auth: { token: "<admin-jwt>" }, // omit for anonymous
});

socket.on("connect", () => {
  console.log("connected", socket.id);
});

Optional rooms

Client emitPayloadEffect
subscribe:project projectId (number) Join room project_<id>
unsubscribe:project projectId (number) Leave room project_<id>
All clients also join realtime. Events are broadcast to every connected client. If authenticated, the socket also joins user_<id>.

Server events

EventWhenPayload
project:created Admin creates a project Full project (owners + tasks)
project:updated Project update, or task create/update/delete (recalculated % / status) Full project (owners + tasks)
task:created Task created Task (TAC as DD-MM-YYYY)
task:updated Task updated Task
task:deleted Task deleted { id, projectId } 
socket.on("project:created", (project) => { /* refresh list / detail */ });
socket.on("project:updated", (project) => { /* refresh list / detail */ });
socket.on("task:created", (task) => { /* ... */ });
socket.on("task:updated", (task) => { /* ... */ });
socket.on("task:deleted", ({ id, projectId }) => { /* ... */ });

// Optional: focus on one project
socket.emit("subscribe:project", 1);
socket.emit("unsubscribe:project", 1);
Task mutations also emit project:updated after totalPercentage and status sync, so UIs can refresh the parent project in one place.

18. Quick Start

# 1) Sign in
curl -X POST http://localhost:3030/api/admin/v1/auth/sign-in \
  -H "Content-Type: application/json" \
  -d '{"email":"developer@ayabank.com","password":"YourPassword1!"}'

# 2) Overview
curl http://localhost:3030/api/admin/v1/overview \
  -H "Authorization: Bearer <token>"

# 3) Create project (FULL_CONTROL)
curl -X POST http://localhost:3030/api/admin/v1/projects \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"New Initiative","ownerIds":[3]}'

# 4) Create task (syncs project % + status + socket events)
curl -X POST http://localhost:3030/api/admin/v1/tasks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Kickoff","tac":"30-07-2026","completedPercentage":25,"projectId":1,"status":"ON_TRACK"}'

# 5) Public dashboard list (no CLOSE projects)
curl http://localhost:3030/api/dashboard/v1/projects

# 6) Socket.IO (browser / Node client)
# connect to http://localhost:3030 path /socket.io
# listen: project:created | project:updated | task:created | task:updated | task:deleted
